Шаблоны служебных записок по дополнительным обязанностям:

- memo-7.docx — школа №7;
- memo-1811.docx — школа №1811;
- memo-demo.docx — резервный шаблон.

Файл для нужной школы можно заменить своим DOCX. Система подставляет значения во все части документа, включая таблицы, колонтитулы и обычные абзацы.

Поддерживаемые плейсхолдеры:

{RECIPIENT_TITLE} — должность и организация адресата;
{RECIPIENT_NAME} — ФИО адресата;
{AUTHOR_POSITION} — должность сотрудника, выпустившего служебную записку;
{AUTHOR_NAME} — ФИО сотрудника, выпустившего служебную записку;
{MEMO_TEXT} — полный текст служебной записки, включая дополнительные обязанности;
{DOCUMENT_DATE} — дата служебной записки.

Не добавляйте отдельный заголовок «О назначении: ...»: назначение уже содержится в {MEMO_TEXT}.
