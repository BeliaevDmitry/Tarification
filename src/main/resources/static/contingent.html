Ручная правка численности классов

        
Здесь можно временно задать численность вручную. Она будет использоваться в расчётах и выгрузках, если выбран источник «Ручной ввод».

        

            
            
        

        

            
            
            
            
            
        

        

        

            

        

    


    

        
Статусы и ИУП

        

            В численности ребёнок с действующим ИУП учитывается только в колонке «ИУП».
            Его исходная категория «Норма / К2 / К3» сохраняется и показывается в реестре ниже.
        

        

            
            
            
            
        

        


        

            Импорт и экспорт всех данных
            

                Скачайте единый Excel-пакет: в нём уже есть текущие данные, справочники и точные заголовки.
                Заполненный файл можно загрузить обратно целиком. Пока данные не прошли контроль,
                действует прежний расчёт; после успешной проверки фактическая численность применяется автоматически.
            

            

                
                
                
                
            

            

            

                

            

        


        

            Подтверждающие документы
            

                Здесь фиксируется приём МСЭ, ИПР/ИПРА, ЦПМПК, ППк, ИОМ и других документов.
                Запись хранит реквизиты, срок действия, форму принятого экземпляра и прикреплённые копии.
                Сам документ не меняет категорию ребёнка автоматически: статус «Норма / К2 / К3» задаётся отдельно.
            

            

                

                    
                    
                    
                    
                    
                    
                    
                    
                    
                    
                    
                    
                    
                    
                    
                

                
Один файл — до 15 МБ. Дополнительные копии можно прикрепить при повторном сохранении записи.
